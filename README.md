# Data Visualization Showcase

Collection of effective data visualization techniques in Python, tailored for computational data science portfolios.

## Examples Included
- Time series line plots (matplotlib)
- Box plots by category (seaborn)
- Correlation heatmaps
- Interactive charts (plotly)
- Bar charts of aggregates

Uses synthetic data inspired by Michigan weather patterns for relevance to MSU students.

## Setup
```bash
pip install -r requirements.txt
python visualization_examples.py
```

Outputs: PNG images and an interactive HTML plot.

## Skills Demonstrated
- Choosing appropriate chart types
- matplotlib and seaborn styling
- Interactive visualization with plotly
- Handling time series and categorical data

Strong portfolio addition for CMSE 402 (Data Visualization Principles & Techniques) and general data science interviews.

Educational project for Michigan State Computational Data Science students.
